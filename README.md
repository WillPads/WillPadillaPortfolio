# Will Padilla: Portfolio

My personal portfolio site: projects, skills, certifications and experience, with links to my resume and contact details.

**Live site:** https://willpadilla-portfolio.vercel.app

| Project | What it is | My role |

| [SyncSpace](https://github.com/WillPads/SyncSpace) | Real-time co-working rooms with a shared Pomodoro clock ([live](https://sync-space-taupe.vercel.app)) | Sole full-stack developer |
| Signal No. 5 | 8-bit RPG that teaches typhoon preparedness, with dialogue from a locally run AI model (AppBuildersPH Local AI Hackathon 2026) | Associate PM, Backend Developer & Pitcher |
| [Gabay Aralin](https://github.com/nananiie/Gabay-Aralin) | Mobile-first AI home tutor for parents and kids (UX+AI Hackathon) | Co-developer |

## Built with

- **Next.js 16** (App Router) with **React 19** and **TypeScript**
- **Tailwind CSS 4**
- **lucide-react** and **simple-icons** for icons
- **Vercel** hosting and Vercel Analytics

## Features

- Project cards with status, role and stack, plus a detail view for each project
- Skills grouped by area, with technology logos
- Certifications carousel
- Light and dark themes
- Responsive layout for mobile and desktop

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
# open http://localhost:3000
```
